# Анкета гостя кофейни

Домашнее задание №1 по .NET MAUI: приложение-анкета, в которой гость кофейни оставляет отзыв о визите.

## Что есть в анкете

| Контрол | Где используется |
|---|---|
| Label | заголовки разделов, подписи полей, вывод результата |
| Entry | имя (`Keyboard="Text"`), телефон (`Keyboard="Telephone"`), e-mail для рассылки (`Keyboard="Email"`) |
| Editor | пожелания гостя |
| Picker | любимый напиток |
| RadioButton | как часто гость бывает в кофейне (группа `VisitFrequency`) |
| CheckBox | что берёт кроме напитков |
| Switch | согласие на рассылку |
| DatePicker | дата визита |
| Slider, Stepper | общая оценка, количество чашек в неделю |
| Image | логотип в шапке |
| Button | «Показать результат», «Очистить» |

## Поведение

- Подпись с оценкой привязана к слайдеру через `x:Reference` (`Path=Value`, `Mode=OneWay`).
- Кнопка «Показать результат» становится активной, когда начато заполнение имени или телефона.
- Поле e-mail появляется только при включённой рассылке.
- «Показать результат» проверяет обязательные поля (имя, телефон, частоту визитов, e-mail при включённой рассылке) и выводит сводку всех ответов.
- «Очистить» возвращает все поля и результат в исходное состояние.

## Запуск

```bash
dotnet build -t:Run -f net9.0-android
```

или `net9.0-maccatalyst` / `net9.0-ios` в зависимости от платформы.
